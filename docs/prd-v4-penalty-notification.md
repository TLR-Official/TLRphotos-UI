## 一、背景与目标

现有用户管理缺乏分级处罚能力，审核员面对违规用户只能全量封禁或仅口头警告，缺少中间梯度；同时用户主页信息展示维度不足，站点缺少官方公告广播渠道。

本迭代目标：
1. 建立三级处罚体系（警告 / 功能封禁 / 直接封禁），实现差异化惩戒；
2. 完善封禁操作界面与多重确认机制，降低误封风险；
3. 优化用户主页信息展示，公开展示处罚状态；
4. 新增站点公告横幅，支持官方内容广播。

## 二、模块一：处罚管理系统（三级分级）

### 2.1 入口与挂载
- 处罚操作主入口：管理后台「用户管理」；
- 快捷入口：支持从**审核界面**、**申诉界面**直接跳转至对应用户的处罚操作页；
- 处罚生效后，用户管理界面同步**暂停对应权限**。

### 2.2 三级处罚规则

| 等级 | 名称 | 公开范围 | 时效 | 限制能力 | 可撤销 |
|------|------|----------|------|----------|--------|
| 1 级 | 仅警告 | 个人主页公开展示警告 + 处罚原因 | 无固定时限 | 不限制点赞等行为 | 可撤销（仅超管） |
| 2 级 | 功能封禁 | 公开展示 + 处罚原因 | 30~360 天（可配置） | 上传图片、发评论、论坛发帖、下载图片 | 可解除 |
| 3 级 | 直接封禁 | 公开展示 + 登录界面拦截 | — | 账号完全封禁 | — |

**说明**：
- 1 级警告不阻断任何功能，仅作警示；
- 2 级功能封禁为可配置能力集，支持按项勾选封禁；
- 3 级直接封禁后用户无法登录。

### 2.3 封禁操作约束
- 用户封禁**仅可在审核界面内执行**（不在用户管理列表直接封禁）；
- 建议在「总审核端」新增「用户封禁管理」统一入口；
- 封禁操作需**多重确认**（二次或多次确认弹窗），避免误操作。

## 三、模块二：高级用户管理（封禁操作界面）

### 3.1 权限项展示
- 用户权限项展示至多 7 项；
- 新增「封禁管理」权限项。

### 3.2 封禁操作表单字段

| 字段 | 说明 |
|------|------|
| 账号与头像 | 显示原头像、新头像，供审核员识别用户身份 |
| 封禁原因 | 必填文本，将公开展示在受罚用户个人主页 |
| 封禁期限 | 30~360 天可选（2 级功能封禁适用） |
| 确认机制 | 多次确认弹窗，防止误封 |

---

## 四、模块三：用户主页页面改善

### 4.1 信息展示优化
- **状态标签体系**：已看、可设置、IP（脱敏显示）、可查看（地区，如广东）、浏览数；
- **已入库图片展示**：原图、预览图、精细图、水印图；原图是否公开展示可配置；
- **作品状态**：未通过 / 已通过 → 归入对应图库（如航空）；
- **论坛发帖记录**：展示该用户的论坛发帖历史。

### 4.2 处罚信息展示
- 1/2/3 级处罚信息在个人主页公开展示（处罚原因、期限）；
- 配色与现有三色体系（淡蓝 / 淡紫 / 深蓝）保持一致。

---

## 五、模块四：公告与通知横幅系统

### 5.1 公告横幅（Top Banner）
- 站点顶部新增公告横幅（Top Banner）；
- 位于顶栏区域，右上角可点击关闭 / 展开；
- 内容结构：封面图 + 标题 + 正文（支持多篇轮播或列表）。

### 5.2 公告与通知区分
- **公告**：站点级广播，所有用户可见；
- **通知**：用户个人通知，复用现有通知中心（V4 已落地）；
- 命名待确认：「公告」是否改为其它名称。

## 六、优先级与排期建议

| 优先级 | 模块 | 理由 |
|--------|------|------|
| P0 | 处罚管理系统（三级分级） | 审核惩戒核心能力，直接影响社区治理 |
| P1 | 高级用户管理（封禁界面） | 处罚系统的操作入口，依赖 2.1 |
| P2 | 用户主页页面改善 | 信息展示优化，含处罚公开 |
| P3 | 公告通知横幅 | 站点广播能力，可独立于处罚体系 |
