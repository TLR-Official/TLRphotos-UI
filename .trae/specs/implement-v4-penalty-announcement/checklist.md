# Checklist — V4 处罚分级与公告横幅迭代验收

## 模块一：三级处罚体系
- [ ] penalties 表含 capabilities/revoked_at/revoked_by 列，存量记录迁移正确（旧 L1→L2+upload、旧 L2→L3）且二次启动不重复迁移
- [ ] L1 警告创建后不限制任何能力，仅产生通知与留痕
- [ ] L2 按项勾选：仅勾「上传」时上传三路径 403 UPLOAD_BANNED（含解禁时间），评论/发帖/下载不受影响
- [ ] L2 四项执法各自生效：评论 403 COMMENT_BANNED、论坛发帖 403 FORUM_POST_BANNED、下载 403 DOWNLOAD_BANNED
- [ ] L2 期限边界：29 天拒绝、30 天与 360 天接受、361 天拒绝；到期后对应能力自动恢复（无需定时任务）
- [ ] L3 永久封禁后登录被拒且现有会话强制下线；限时 30 天到期后登录自愈放行
- [ ] L1 撤销仅 super 可执行（他人 403 BAN_MANAGE_DENIED）；L2/L3 解除清除对应效果并通知用户
- [ ] 全部处罚/撤销端点挂人机验证门，reason 必填，处罚历史含 capabilities 与撤销状态
- [ ] 对管理员账号施加处罚仅留痕不落效果（沿用现行为）

## 模块二：封禁操作界面
- [ ] /admin/bans 页可用：搜索用户、展示原头像与账号、等级切换、L2 能力勾选、期限选择、原因必填
- [ ] 提交触发多重确认弹窗（不少于两次确认，展示处罚摘要）
- [ ] UsersPage 无直接处罚/封禁入口，跳转 /admin/bans?userId=xxx 正常预选用户
- [ ] 审核界面与申诉界面均有「处罚该用户」快捷跳转
- [ ] 无 can_ban_manage 权限访问封禁管理被拦截（前端隐藏+后端 403）
- [ ] 用户权限项展示 7 项，含新增「封禁管理」开关并挂验证门

## 模块三：公开用户主页
- [ ] /users/:id 渲染状态标签（省份/加入天数/作品总浏览/处罚徽章）、处罚公开卡（三色配色）、作品分区展示、论坛发帖记录
- [ ] 公开端点仅返回 approved 作品，未通过作品对非本人不可见，响应不含明文 IP
- [ ] 本人视图显示待审/未通过计数与「我的作品」链接
- [ ] 评论区/帖子/照片详情作者名可点击跳转对应用户主页
- [ ] 登录/注册后 users.region 写入省份，解析失败写「未知」且不影响登录；不落明文 IP

## 模块四：公告横幅
- [ ] announcements 表落库；管理端可新建/编辑/删除/上下线（super 与 news_editor 可用，他人 403）
- [ ] GET /api/announcements 仅返回 is_active 公告，下线后前台消失
- [ ] TopBanner 位于站点顶部 Header 之上，含封面图+标题+正文，多条列表展开
- [ ] 右上角可关闭/展开，关闭状态按公告 id 在 localStorage 记忆，刷新不重复弹出
- [ ] 公告接口失败时横幅静默隐藏，不影响页面其余功能
